Two things the form must get right

  • Skip must write "none", not silence. The create route refuses a submission that says nothing about accent, tagline, intro and rates — an explicit decline is a recorded answer. A form that just omits them would be more permissive than the chat path it replaces
  • Visibility stays on screen one. Burying it is how "only my daughter should read this" becomes a public journal — a mistake this project has already made once and hunted a false negative for once more

And one control not to build

No "make this the current trip" toggle. Status is already derived from the dates on every read — deriveStatus() — and v2 trip.json stores no status field at all. A toggle would resurrect exactly the bug the migration retired: a flag that disagrees with its own dates, set in March and still claiming "current" in November.

Say it once, plainly, and add no control: "Whichever trip's dates include today shows as current — you never have to flip a switch."

So what is /agent for?

The conversational fallback for everything that has an owner-only cookie, a browser, and no dedicated page yet — money interviews, party and visibility edits, reminders, print proposals. The long tail too varied to justify a screen, but too irreversible-adjacent for WhatsApp's phone-level trust.

Its footprint should shrink every time a "to build" becomes a page. When a repeated action earns a form, prune the tool — don't keep a parallel path. /agent is not a second front door to the same features.

The security boundary

Restricting what the model is offered is not a restriction. switch_area advertises every area and can widen back to all of them, and a tool list is advisory at best.

  • Narrow the candidate areas before pickArea() runs
  • Narrow switch_area's own enum to match
  • Refuse in runTool on caller kind — this is the only line that actually holds

Before any of it

What needs you, not us

  • Hungarian. Every string across all three concepts has English and German. Hungarian is unwritten — the repo rule forbids inventing one, so this is a hand-off to a speaker, not a task
  • Is 3 days the right tail for "the trip just ended"? It covers the flight home plus one jetlagged evening
  • Does /agent survive long-term, or is it explicitly a holding pen that shrinks to nothing as pages get built?
  • Which overlapping tickets get folded in — B1595 (inbox day-assembly), B1797 (import framing, in testing), B1807 (staging size limit), B1571 (costs/contacts refused when full)
  • 1 Oct 2026 is six weeks out. If in-window replies become billable, the "at most two asks" rule becomes a cost model. Worth deciding now whether the funnel gets a per-day message budget
  • Screenshot maintenance. Google moved the Timeline export once already; a screenshot that lies is worse than prose
